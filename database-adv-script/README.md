# 🔗 SQL Joins – Airbnb Database Project

## 📌 About
This repository contains **SQL join queries** written as part of the **ALX Airbnb Database Module**.  
The focus is to **master SQL joins** and **subqueries** by writing complex queries across multiple tables in a simulated Airbnb schema.  

The queries are stored in the `join_queries.sql`file and demonstrate how to combine data from different tables (`users`, `bookings`, `properties`, `reviews`) to answer real-world business questions.
